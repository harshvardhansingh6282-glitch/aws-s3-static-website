# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates how to host a static portfolio website using Amazon S3.

## AWS Services Used
- Amazon S3
- S3 Static Website Hosting
- S3 Bucket Policy

## Technologies
- HTML
- CSS
- AWS Cloud

## Project Steps
1. Created an S3 bucket in the Mumbai region (`ap-south-1`).
2. Created a portfolio website using HTML and CSS.
3. Uploaded `index.html` to Amazon S3.
4. Enabled static website hosting.
5. Configured bucket permissions for public website access.
6. Tested the website using the S3 website endpoint.

## Skills Learned
- AWS S3 bucket creation
- Object uploads
- Static website hosting
- Bucket policies and public access permissions
